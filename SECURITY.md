# Security Policy

## Supported Versions

Security updates are applied to the latest stable release of Parikshan.

| Version | Supported          |
| ------- | ------------------ |
| 0.0.x   | :white_check_mark: |
| < 0.0.8 | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability in Parikshan, please do not report it in public issue trackers.

Instead, report it via:
1. **GitHub Security Advisory**: Open a draft advisory under the **Security** tab of this repository.
2. **Email**: Send vulnerability details to `aryapreetam@gmail.com`.

Please include:
- A description of the issue and potential impact.
- Steps to reproduce or a minimal proof of concept.
- Affected platforms (Android, iOS, Desktop, Wasm) and library versions.

We acknowledge receipt of reports within 48 hours and coordinate a fix before public disclosure.
